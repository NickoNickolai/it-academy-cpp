# Exploding Kittens

Реализация настольной карточной игры "Взрывные Котята". Поддержка игры против компьютера.

## Игровая колода

Игровая колода содержит 52 карты:

- `EXPLODE` (4 шт)
- `DEFUSE` (6 шт)
- `ATTACK` (4 шт)
- `SHUFFLE` (4 шт)
- `SKIP` (4 шт)
- `NOPE` (5 шт)
- `FUTURE` (5 шт)
- `FAVOR` (4 шт)
- `CAT` (16 шт)

Фактическое количество карт `EXPLODE` и `DEFUSE` определяется числом игроков:

```
explodes = players - 1
defuses = players + 1
```

## Назначение карт

- `EXPLODE` - игрок взрывается и проигрывает, если не может отбиться картой `DEFUSE`
- `DEFUSE` - отменяет действие карты `EXPLODE`, переход хода к следующему игроку
- `ATTACK` - следующий игрок делает 2 хода подряд, переход хода к следующему игроку
- `SHUFFLE` - перетасовка колоды, текущий игрок тянет карту
- `SKIP` - пропуск хода вместо того, чтобы тянуть карту, переход хода к следующему игроку
- `NOPE` - отмена действий карт `ATTACK`, `SKIP`, `SHUFFLE`, `FUTURE`, `FAVOR`, ход возвращается к предыдущему игроку
- `FUTURE` - подсмотреть 3 верхние карты в колоде, текущий игрок тянет карту
- `FAVOR` - следующий игрок отдает 1 карту на свой выбор текущему, текущий игрок тянет карту
- `CAT` - бесполезная карта

## Правила игры

В начале игры каждому игроку раздается по 5 карт из колоды основных карт + 1 карта `DEFUSE`.

Затем в соответствии с числом игроков в колоду добавляются карты `EXPLODE` и `DEFUSE`.

Игроки ходят по почереди.

В начале своего хода игрок должен либо походить одной из своих карт, либо не играть свою карту вовсе. При этом если игрок сыграл карту и её действие можно отменить, то следующему игроку отправляется запрос на отмену. Если такой запрос удовлетворяется, то ход возвращается и текущий игрок должен начать свой ход заново.

Если отмены не происходит, то текущий игрок должен выполнить действие, предписанное сыгранной картой. При этом ход либо переходит следующему игроку либо начинается ход колоды.

Колода играет карту на текущего игрока. Если карта не `EXPLODE`, то игрок забирает ее себе в руку и ход переходит к следующему игроку. В противном случае игрок должен отбиться картой `DEFUSE` либо проигрывает.

Игра заканчивается когда остается лишь 1 игрок.

## Интерфейс

Реализован консольный интерфейс для игры против компьютера.

## Зависимости

Игра написана на C++ c использованием фреймворка [Qt](https://www.qt.io/download-dev).
